# Security Policy

## Supported Project Scope

This repository is a static Three.js/WebGL portfolio template with a small
Node/webpack development workflow. Security maintenance focuses on build
tooling, dependency advisories, and any issue that could affect users who fork
or deploy the template.

## Reporting a Vulnerability

Please do not open public issues for sensitive security reports. Instead,
contact the maintainer through the email listed on the GitHub profile:

<https://github.com/AirHua-byte>

Include:

- affected package, file, or workflow;
- steps to reproduce;
- potential impact;
- suggested fix, if you have one.

The maintainer will review reports as soon as possible and may publish a fix,
documentation note, or dependency update depending on the severity.
