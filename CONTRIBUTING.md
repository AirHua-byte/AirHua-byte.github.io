# Contributing

Thanks for taking the time to improve this Three.js personal website template.

## What Helps

- documentation fixes for setup, deployment, and customization;
- small compatibility fixes for current Node.js and browser versions;
- asset replacement examples for portfolio links, textures, and billboards;
- security or dependency maintenance with clear reproduction steps.

## Local Development

```bash
npm install
npm run dev
```

Build the static site before opening a pull request:

```bash
npm run build
```

## Pull Requests

Keep pull requests focused and include:

- what changed;
- how you tested it;
- screenshots or a short screen recording for visual changes.

For dependency updates, mention the package, the security advisory or reason,
and whether the generated build output changed.
